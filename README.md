## 🚀 100% Free Deployment Options

### Option 1: Deploy to Vercel (Recommended & Easiest)
1. Go to [Vercel](https://vercel.com/) and sign in with your GitHub account.
2. Click **"Add New Project"** and select this repository.
3. Keep default settings (`Framework: Vite`, `Build Command: npm run build`, `Output Directory: dist`).
4. Click **Deploy**. Your portfolio will be live in 30 seconds with a free `.vercel.app` domain!

### Option 2: Deploy to GitHub Pages (Automatic)
1. Go to your repository on GitHub.
2. Navigate to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select **GitHub Actions**.
4. Push to `main` — GitHub will automatically build and publish your site at `https://<your-username>.github.io/<repo-name>/`.

### Option 3: Deploy to Netlify
1. Go to [Netlify](https://www.netlify.com/) and sign in with GitHub.
2. Click **"Import from Git"** and choose this repository.
3. Click **Deploy Site**.
